## ⭐ What I'm building

### 🕷️ [Onwebs SEO & GEO](https://github.com/AmirMoghtader/onwebs-seo-geo) — *free, open-source Screaming Frog alternative*

[![Stars](https://img.shields.io/github/stars/AmirMoghtader/onwebs-seo-geo?style=flat&color=1E3A6F)](https://github.com/AmirMoghtader/onwebs-seo-geo/stargazers)
[![License](https://img.shields.io/badge/license-GPL--3.0-blue)](https://github.com/AmirMoghtader/onwebs-seo-geo/blob/main/LICENSE)
[![Platforms](https://img.shields.io/badge/macOS%20·%20Windows%20·%20Linux-2B6CC4)](https://github.com/AmirMoghtader/onwebs-seo-geo/releases)
[![Telemetry](https://img.shields.io/badge/telemetry-none-brightgreen)](https://github.com/AmirMoghtader/onwebs-seo-geo)

An unlimited desktop SEO crawler with a **GEO / AI-search toolkit** Screaming Frog doesn't have — free forever, no 500-URL cap, no subscription. Built in **Rust** and **Next.js**, packaged with **Tauri**: ~25 MB app, ~57 MB RAM at idle, zero telemetry.

- Deep crawler with **full Internal-tab parity — all 73 columns**, pages + images + JS + CSS in one view, complete CSV export
- **Log file analyser** with AI-bot breakdowns — GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot
- Redirect chains as rows, Include/Exclude patterns, List mode, three crawl-speed profiles
- Core Web Vitals, XML sitemap analysis, robots.txt inspection, orphan-page detection, crawl diff
- Connectors: PageSpeed Insights, GA4, Search Console, Clarity, Power BI, Ollama & Gemini
- **Persian-first bilingual UI** — the only serious crawler with first-class فارسی

`Rust` · `Tauri` · `Next.js` · `TypeScript` · `GPL-3.0` — [Download](https://github.com/AmirMoghtader/onwebs-seo-geo/releases) · [seo.onwebs.ir](https://seo.onwebs.ir)

## 🔍 SEO & GEO

Beyond building the site, I make sure it gets found. Technical SEO, schema markup, Core Web Vitals, internal linking and content architecture — plus **GEO** (Generative Engine Optimization): structuring pages so they're citable by AI Overviews, ChatGPT and Perplexity, not just ranked by Google. Most sites are invisible to AI search. That's the gap I work in.

Shipped on real projects: per-doctor server-side SEO and local/GEO optimization on Avanobat, an SEO-driven blog platform with auto-generated sitemaps — and the crawler above, which I built because I needed it.
